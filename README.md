# 💰 Crypto Tracker

Быстрый трекер криптовалют: цены, графики, ручной портфель, аналитика кошельков и новости.

**Live:** https://0xvilya.github.io/crypto-tracker/

## v9 — исправления и улучшения

- ✅ Полная кликабельность всех кнопок, навигации, списка, трендов
- 🔍 Рабочий поиск монет (CoinGecko) + добавление в watchlist
- 💰 Стабильный ручной портфель с чипами и поиском
- 📊 Графики + fallback
- 👛 Аналитика кошельков (ETH/BSC/Polygon/Arbitrum/Optimism/Base/Solana/TON/Bitcoin)
- 🔗 **Tonkeeper / TON Connect** — кнопка подключения кошелька
- 📰 Новости, конвертер, gas, DCA, цель прибыли, доминация
- 🌙 Тёмная / светлая тема (фиолетовая сохранена), RU/EN, валюты
- ⚡ Кэширование цен, устойчивые fallback-ы

## Возможности

- Watchlist с поиском и топ-монетами
- Детальная карточка монеты + ссылки на биржи
- Ручной портфель + P&L + pie-chart
- Аналитика кошелька по адресу
- Конвертер, gas, DCA, цель прибыли, доминация
- Export / Import (JSON/CSV) — базовая поддержка

## Технологии

- Pure HTML / CSS / JS (без сборки)
- CoinGecko public API + Binance US
- TON Connect UI (Tonkeeper и другие TON-кошельки)
- Публичные RPC

## Локальный запуск

Откройте `index.html` в браузере или через любой static server.
